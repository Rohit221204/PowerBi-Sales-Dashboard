Power BI Sales Analytics Dashboard

Project Overview

An interactive Sales Analytics Dashboard developed using Microsoft Power BI to analyze business performance and generate meaningful insights.

Dashboard Pages
1. Key Insights

- Total Revenue
- Sales Quantity
- Revenue by Markets
- Sales Quantity by Markets
- Top 5 Customers
- Top 5 Products

- 2. Profit Analysis

- Revenue Contribution by Market
- Profit Contribution by Market
- Profit Margin Analysis
- Customer-wise Profit Analysis

3. Performance Insights

- Market Performance Analysis
- Revenue Trend
- Profit Margin Percentage
- Customer Performance

- Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

Key Features

- Interactive Dashboard
- Dynamic Filters
- Market-wise Analysis
- Revenue and Profit Analysis
- Customer and Product Insights
